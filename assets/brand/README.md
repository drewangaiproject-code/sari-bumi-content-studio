# Brand Asset Inventory

This folder is reserved for official SARI BUMI brand assets approved for use in this repository.

**No legacy brand assets are copied during initial setup.**

## Inventory fields
For each candidate asset, record:
- Asset name and type.
- Current source location in the old repository or Owner source.
- Owner/source confirmation.
- Version or date, if known.
- Review status: `PENDING_REVIEW`, `APPROVED_FOR_USE`, or `REJECTED`.
- Notes on allowed use and any restrictions.

## Rules
- The logo must be the Owner-provided source asset; do not redraw, retype, recolor, or substitute it.
- Colors and fonts recorded in project notes are references until checked against authoritative brand files.
- Do not copy files into this folder until the Owner approves the inventory decision.
- Do not overwrite or modify source assets.
