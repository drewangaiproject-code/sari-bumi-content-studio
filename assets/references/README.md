# Legacy Asset Inventory

This folder is for the inventory process and approved reference decisions. During initial setup, do not copy SVG, storyboard, animation, logo, photography, or other assets from the old repository.

## Inventory template

Create an inventory entry in the review notes or a future approved inventory file with these fields:
- Inventory ID.
- Asset name and type.
- Exact source path or URL in the old repository.
- Related content/product, if known.
- Owner/source and rights status, if known.
- Technical status: opens/renders, dimensions, dependencies, and export state where applicable.
- Creative status: brand consistency, legibility, factual accuracy, and relevance.
- Existing approval status and evidence.
- Review result: `PENDING_REVIEW`, `APPROVED_FOR_REFERENCE`, `APPROVED_FOR_REUSE`, or `REJECTED`.
- Reviewer/date and reason.

## Review rules

- An old file's presence is not evidence of approval.
- Conflicting or withdrawn approval statuses must be resolved with the Owner.
- Keep reusable visual assets separate from drafts and examples.
- Do not copy any asset until it has an explicit approved reuse decision.
- Inventory first; import later only with separate approval.
