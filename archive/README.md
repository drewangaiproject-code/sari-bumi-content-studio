# Legacy Project Reference Policy

The previous repository remains unchanged and serves as a read-only reference during the rebuild.

## Rules
- Do not bulk-copy or mirror the old repository.
- Use source paths and notes in the inventory to point to candidate materials.
- Review conflicting instructions, test counts, content statuses, and approvals before relying on them.
- Treat old drafts as benchmarks or references, not as approved current content.
- Do not delete, rename, or modify the previous repository as part of this project.
- Copy an asset or document only after the Owner explicitly approves that specific reuse decision.

No legacy assets or documents have been imported during initial setup.
