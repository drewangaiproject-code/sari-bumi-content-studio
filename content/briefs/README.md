# Content Briefs

Store one brief per content item in this folder.

## Minimum brief fields
- Content ID and version.
- Product/SKU.
- Objective.
- Target audience or audience hypothesis.
- Platform and format.
- Duration/slide count or length.
- Core message and intended payoff.
- CTA preference, if any.
- Verified product facts allowed for use.
- Claims or topics to avoid.
- Owner-provided references/assets.
- Open questions.
- Status and Owner decision.

Mark unknown details as pending. Do not invent missing product facts. Use `BRIEF_DRAFT` until the brief is ready for writing.
